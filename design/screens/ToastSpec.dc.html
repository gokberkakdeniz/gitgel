Toast

One at a time, bottom centre (bg.hover on border.strong, radius 12, popover shadow); the screen positions it. An optional status icon (running spinner, success, failed), the message with an optional mono part first (code), a mono sub line, then an action button and a link. A toast with a status (a script run) is clickable as a whole (it opens the run’s output; hover bg.pressed) and ends with a 24px ✕ that dismisses it; the script keeps running. While the run’s output panel is open it has no toast; closing the panel while it still runs brings the toast back.
